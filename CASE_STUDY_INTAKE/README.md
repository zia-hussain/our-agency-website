# Case Study Intake

Use this folder for raw project proof before it becomes public site content.

Create one folder per project:

```text
CASE_STUDY_INTAKE/project-slug/
  brief.md
  screenshots/
  workflow/
```

Videos should stay as Loom, YouTube, or Vimeo links inside `brief.md`.

When screenshots are approved for the website, optimized WebP files should move to:

```text
public/case-studies/project-slug/
```

Default visibility for new proof pages is `private-proof`. That keeps the page useful for proposals while avoiding Google indexing until client approval is clear.
